shapez 通用机器求解器

输入任意 shape code，输出能把它造出来的建筑方案（可验证）

目标形状

层与层之间用 : 分隔；每个象限两位：形状 C R S W + 颜色 r g b y p c w u，空位写 --

关卡目标

可用建筑（默认全部）

关卡模式下会自动限制为该关卡时已解锁的建筑 —— 这决定了能不能用四色上色器、四向切割机等。

象限顺序 / 图例
q3 左上
q0 右上
q2 左下
q1 右下

shape code 按 q0,q1,q2,q3 的顺序每象限两位。
堆叠器：下层保持不动，上层下落，直到每个象限的最小间隙为 1 层。

生产方案

等待输入…

地图 → 建筑图纸

读取当前游戏的存档得到地图种子，按目标 shape 选最近的矿脉，输出放置清单 + 图纸。 需要在和游戏同一个源下打开本页（http://127.0.0.1:8087/solver/web/）才能读到游戏的 IndexedDB。

语义与 shapez.io 1.5.7 一致：旋转/切割/堆叠/上色全部按官方实现模拟，方案生成后会自动复算校验。
