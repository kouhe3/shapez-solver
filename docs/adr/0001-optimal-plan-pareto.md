# 优解 = 交付效率与占用格的帕累托前沿

- Status: accepted
- Date: 2026-11-16

shapez 1.5.7 的地图无限、设施免费、传送带速度固定（2 件/秒）且不衰减，带满后是流式、没有启动延迟；因此建筑数量本身不是成本，稀缺的是中心入口和地图格。**优解**定义为「交付效率（送入中心/秒）」与「占用格」两轴上的帕累托前沿：不存在另一个方案同时交付更快且占用更少；交付效率的上限是中心入口格数 × 传送带额定速度（当前 16 × 2 = 32 件/秒），到上限后继续加设施不再提高交付。优解不是一个方案，而是未被支配的 `(rate, tiles)` 集合；在上限点上取占用格最少者。

## Considered Options

- **建筑数最少**（当前 `planShape` 的 `cost`）：与「设施免费」冲突，且不区分 1×1 / 4×1 / 垃圾桶 / 带格。
- **交付时间最少**（单目标）：交付上限相同（32/s）时无法区分方案，且忽略占用格。
- **传送带总长度最少**：只是占用格的一部分，忽略建筑本体与端口。

## Consequences

- `cost` 是搜索标量，不是优解判据；`aborted=false` 不证明优解。
- 判定优解需要每个方案的 `(rate, tiles)`、目标/需求上的枚举或下界，并输出前沿而不是单点。
- README 的「成本最优」与 AGENTS 的「cost=建筑数」从此按代理指标读。
